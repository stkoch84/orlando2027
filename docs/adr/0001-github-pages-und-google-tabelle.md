# Eigene Webseite auf GitHub Pages mit Google-Tabelle als Speicher

Das Tool läuft als statische Seite auf GitHub Pages und speichert die Bewertungen über ein Apps-Script in einer Google-Tabelle in Papas Konto. Ein Claude-Artifact mit eingebautem Speicher wäre schneller gewesen. Es wurde verworfen, weil nicht alle Familienmitglieder einen claude.ai-Zugang haben und das Tool mit einem normalen Link ohne Konto funktionieren muss.

## Consequences

Die Abstimmung ist verdeckt, aber nicht geheim. Wer die Browser-Entwicklerwerkzeuge nutzt, kann die Bewertungen der anderen vor dem Aufdecken auslesen. Das wird innerhalb der Familie bewusst in Kauf genommen.
